# ხელობა — ქართველი ხელოსნების ონლაინ მაღაზია

სასწავლო პროექტი: React-ზე აწყობილი ონლაინ მაღაზია, სადაც ხელოსნები (კერამიკა, მინანქარი, თექა, ფარდაგი, ხის ნაკეთობა) ყიდიან თავიანთ ნივთებს.

## გაშვება

საჭიროა [Node.js](https://nodejs.org) (ვერსია 18 ან უფრო ახალი).

```bash
npm install        # დამოკიდებულებების დაყენება (ერთხელ)
npm run dev        # დეველოპმენტ სერვერი → http://localhost:5173
npm run build      # საბოლოო ვერსია dist/ საქაღალდეში
npm run build:single  # ვერსია, რომელიც ბრაუზერში სერვერის გარეშე იხსნება (dist-single/)
```

`dist-single/index.html` შეიძლება პირდაპირ ბრაუზერში გაიხსნას (`products` საქაღალდე მის გვერდით უნდა იყოს) — ინტერნეტი მხოლოდ შრიფტებისთვის სჭირდება.

## იმიტაციის ფარგლები

პროექტს სერვერი არ აქვს, ამიტომ:

- **მონაცემთა ბაზა** — ყველა მონაცემი (კალათა, შეკვეთები, შეფასებები, შეტყობინებები, პროდუქტების ცვლილებები) ინახება ბრაუზერის `localStorage`-ში. გვერდის განახლების შემდეგ რჩება, მაგრამ სხვა კომპიუტერზე არ ჩანს.
- **ონლაინ გადახდა** — იმიტირებულია (1.2 წამიანი „დამუშავება"). ბარათის მონაცემები არ მოითხოვება.
- **ელფოსტა / SMS** — რეალურად არ იგზავნება.
- **მართვის პანელი** — პაროლით დაცული არ არის, რომ დემონსტრაციისას ადვილად გაიხსნას.

რეალურ ვერსიაში ეს ნაწილები ჩანაცვლდება: Node.js/Express ან Firebase სერვერით, PostgreSQL/Firestore ბაზით, ბანკის გადახდის სისტემით (TBC Pay, BOG iPay) და ადმინის ავტორიზაციით.

## ტექნოლოგიები

- **React 18** — ინტერფეისი კომპონენტებად
- **Vite** — დეველოპმენტ სერვერი და build
- **Context API + useReducer** — მაღაზიის მდგომარეობის მართვა
- **localStorage** — მონაცემების შენახვა
- **CSS** (ცვლადები, Grid, Flexbox, media queries) — დიზაინი და ადაპტაცია
- **SVG** — ლოგო, ხატულები და ილუსტრაცია ფოტოს გარეშე დამატებული ნივთისთვის

## სტრუქტურა

```
src/
├── main.jsx              აპლიკაციის გაშვება
├── App.jsx               გვერდების გადართვა (როუტინგი)
├── router.js             hash-როუტერი (#shop, #product-4 ...)
├── index.css             ყველა სტილი
├── data/products.js      პროდუქტები, კატეგორიები, მიწოდება, პრომოკოდები
├── store/ShopContext.jsx მდგომარეობა: კალათა, შეკვეთები, localStorage
├── utils/format.js       ფასის ფორმატი, ფორმების ვალიდაცია
├── utils/totals.js       შეკვეთის ჯამის გამოთვლა
├── components/
│   ├── Layout.jsx        Header, Footer, შეტყობინება (toast)
│   ├── ui.jsx            ღილაკები, ფორმის ველი, პროდუქტის ბარათი...
│   └── ProductArt.jsx    პროდუქტის ფოტო (ან SVG, თუ ფოტო არ აქვს)
└── pages/                თითოეული გვერდი ცალკე ფაილში

public/products/          პროდუქტების ფოტოები
```

## ახალი ფოტოს დამატება

1. ფოტო ჩააგდეთ `public/products/` საქაღალდეში (სასურველია JPG, 1000 პიქსელამდე).
2. `src/data/products.js`-ში ნივთს მიუწერეთ `image: 'products/ფაილის-სახელი.jpg'`.
3. თუ კვადრატულ ბარათზე ფოტოს საჭირო ნაწილი ჭრის, დაამატეთ მაგ. `imagePos: 'center 30%'`.
4. სასურველია იმავე საქაღალდეში პატარა ვერსიაც: `ფაილის-სახელი-500.webp` (500 პიქსელი). თუ არ არის, საიტი ორიგინალს აჩვენებს.

## ონლაინ გამოქვეყნება (უფასოდ)
